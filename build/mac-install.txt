FUNKDATION 播出系統（Mac 版）安裝方式

1. 把 FUNKDATION.app 拖到「應用程式」資料夾。
2. 第一次開啟：因為這個軟體沒有向 Apple 付費認證，Mac 會擋下來。
   請到「系統設定 → 隱私權與安全性」，往下捲，按「強制打開」（或「仍要打開」），輸入密碼即可。
   之後就能正常雙擊開啟。
3. 如果看到「已損毀，無法打開」：打開「終端機」，貼上下面這行按 Enter，再重新開啟：
   xattr -cr /Applications/FUNKDATION.app
4. 若詢問是否允許存取「文件」資料夾，請按「允許」，賽事資料會存在「文件 / FUNKDATION 賽事資料」。

請確認下載的是正確版本：
- Apple 晶片（M1、M2、M3、M4…）：AppleSilicon 版
- Intel 處理器：Intel 版
（左上角蘋果選單 → 關於這台 Mac，看「晶片」或「處理器」）
