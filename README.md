# FUNKDATION VOL.4 賽事播出系統

Locking 團體對戰賽的現場播出軟體：控制台按 GO 切換畫面、輸入比分、蓋印章、倒數計時，輸出畫面即時更新。不需要網路，所有修改自動存檔。

## 下載

到右側 **Releases** 下載最新版本：

| 電腦 | 檔案 |
| --- | --- |
| Windows | `Windows-Setup.exe`（安裝版）或 `Windows-Portable.exe`（免安裝） |
| Mac（M1／M2／M3／M4） | `Mac-AppleSilicon.zip` |
| Mac（Intel） | `Mac-Intel.zip` |

第一次開啟時：
- **Windows** 出現「Windows 已保護您的電腦」→ 按「其他資訊」→「仍要執行」
- **Mac** 被擋下 → 「系統設定 → 隱私權與安全性」往下捲，按「強制打開」；若顯示「已損毀」，在終端機執行 `xattr -cr /Applications/FUNKDATION.app`

## 版本更新

程式開啟約 5 秒後會自動檢查新版本，有新版就跳出「發現新版本，是否下載並更新？」，按「下載並更新」會自動下載、安裝並重新開啟，賽事資料都會保留。也可以在 **設定 → 版本與更新** 按「檢查更新」。
- Mac 必須先把 FUNKDATION 放在「應用程式」資料夾才能自動更新
- 演出進行中請不要更新

## 使用流程

1. **隊伍**頁：填隊名、上傳照片（去背 PNG 會自動裁掉透明邊）
1. **評審／MC／DJ**頁：上方切換評審、MC、DJ，填名字、Crew／城市、上傳照片；到流程左下角選「評審表演」「MC 介紹」「DJ 介紹」新增，或按「產生評審」一次加入全部評審
2. **贊助商**頁：上傳 Logo
3. **素材與字型**頁：上傳照片外框、字型
4. **流程 → 編排**：點每個 Cue 設定底圖、版面、動畫，上方即時預覽
5. 接上投影機，按右上角 **開啟輸出畫面**
6. **流程 → 演出**：按 GO（空白鍵）依序播出

## 九隊總覽

上排 4 隊、下排 5 隊（可改成上 5 下 4），照片與隊名依「隊伍」頁順序逐隊登場，上方有「LINE UP／參賽隊伍」標題（可修改或留空）。照片大小、間距、上下排位置、字級與每隊間隔都可以調整；關掉「顯示隊伍」就只顯示底圖（例如自己做好的影片）。

## 評審表演／MC 介紹／DJ 介紹

三種排版相同、各自獨立設定。MC 預設懸念文字「YOUR MC IS...／本場主持」、DJ 為「YOUR DJ IS...／本場 DJ」，稱號分別是 MC、DJ。
播到評審 Cue 時先出現「NEXT JUDGE IS... / 下一位評審」，停頓後評審照片、名字、Crew 與「JUDGE」稱號依序登場，表演結束按 X 退場。
懸念文字、稱號、照片比例（橫式、正方形、直式）、版面與動畫都在評審 Cue 右側設定；演出中也可按「直接顯示評審」跳過懸念。

## 表演賽（特邀隊伍）

三十聯軍 VS 華岡藝校，流程放在「評審討論」之後（可拖拉調整），計分畫面與四強賽相同：EXHIBITION／表演賽、4 回合、比分、Timer、勝方印章（按「確認勝方」）。
- 兩隊在「隊伍」頁勾選「表演賽」：不列入九隊總覽、四強與頒獎選單
- 沒有隊伍照片，用 Logo：照片設定勾「Logo 模式」（不顯示外框、可放大），並可勾「不顯示隊名」（Logo 已含隊名）
- 兩隊 Logo 已內建（透明背景），也可以換成新的 PNG

## 四強對戰組合與頒獎

- 「評審討論」播出時，演出面板（和演出小面板）就可以先選四強；輸出畫面不會有變化，播到「四強公布」直接揭曉即可。其他待機 Cue 可在編排的「四強選隊」打開
- 四強依晉級名次填入：**四強對戰 1 = 第 1 名 vs 第 4 名**，**四強對戰 2 = 第 2 名 vs 第 3 名**，揭曉順序為對戰 1 的兩隊 → 對戰 2 的兩隊
- 頒獎沒有亞軍，分成**排舞賽冠軍**（演出時在頒獎 Cue 直接選隊）與 **Battle 冠軍**（自動帶入決賽勝方），兩者可以是同一隊

## 演出小面板（搭配 OBS／Arena）

控制台右上角「演出小面板」（或選單「輸出 → 演出小面板」，Ctrl／⌘＋Shift＋M）會開一個**永遠在最上層**的小視窗，可以放在 Arena 旁邊：
- 播出中／下一個 Cue、GO、上一個、回主視覺、黑畫面
- 播出中 Cue 的所有操作：比分、回合、印章、Timer、晉級、單隊／評審退場、四強揭曉、頒獎
- 快捷鍵與控制台相同（小面板有焦點時）；按「置頂」可切換是否永遠在最上層
- 不放監看畫面，不佔電腦資源；畫面請直接看 OBS／Arena

## 遙控網頁（手機加減分、選四強、Timer）

1. 控制台「設定 → 遙控網頁」：勾「開啟遙控網頁」，設定密碼（至少 4 個字）
2. 手機連上**和播出電腦同一個 Wi-Fi**（不需要網際網路，現場路由器或手機熱點都可以），掃設定頁的 QR Code 或輸入網址 `http://<電腦的 IP>:3010/remote/`
3. 輸入密碼後即可：
   - **比分**：選場次（預設跟著播出畫面自動切換），按 +1／+2／−1，輸出畫面會立即顯示並播放比分動畫；控制台可以復原
   - **Timer**：比分下方的倒數計時，開始／暫停、重置、30／45／60 秒
   - **四強**：依晉級名次（第 1 名 vs 第 4 名、第 2 名 vs 第 3 名）選隊，不能重複選，表演賽隊伍不會出現在選單

### 到現場換網路（例如改用手機熱點）

電腦的 IP 會跟著網路改變，所以遙控網址也會變：
1. 播出電腦連上現場要用的網路（例如你的手機熱點）
2. 開控制台「設定」，遙控網址與 QR Code 會自動換成新的（設定頁開著時換網路，約 4 秒內自動更新）
3. 工作人員的手機連**同一個熱點**，重新掃 QR Code、重新輸入密碼（密碼不變）

彩排時請用現場的熱點實際連一次。有好幾組網址時，用和手機同一個網路的那一組（iPhone 熱點通常是 172.20.10 開頭）。

### Timer 專用（給計時人員）

- 設定頁可另外設「Timer 專用密碼」（選填，不能和完整遙控密碼一樣）
- 網址 `http://<電腦的 IP>:3010/timer`（設定頁有專用 QR Code）：只有大大的倒數、開始／暫停、重置、30／45／60 秒與自訂秒數，手機直拿橫拿都可以
- 用 Timer 專用密碼登入的人只能控制 Timer，改不了比分與四強；只換 Timer 專用密碼時，只有 Timer 專用的手機需要重新登入

安全性：
- 同網路的其他裝置只能開遙控網頁與輸出畫面（唯讀），打不開控制台，也不能上傳、匯出或修改其他設定
- 密碼只存在這台電腦，不會同步給其他裝置；換密碼或關閉遙控網頁，所有手機都要重新登入；連續猜錯 8 次會鎖 5 分鐘
- 第一次開啟時 Windows 防火牆或 Mac 若詢問是否允許連線，請選允許（私人網路），手機才連得上

## 演出快捷鍵

| 按鍵 | 動作 |
| --- | --- |
| 空白鍵 | GO，播下一個 Cue |
| B | 黑畫面 |
| X | 單隊／評審／MC／DJ 退場 |
| T／R | Timer 開始暫停／重置 |
| ← → ↓ | 左方勝印章／右方勝印章／印章淡出 |
| 1 2 3 | 排舞賽冠軍揭曉／Battle 冠軍揭曉／兩位冠軍同框 |
| Q W E Esc | 直接切換單獨排舞賽冠軍／單獨 Battle 冠軍／同框／底圖 |

## 資料與備份

- 資料存在「文件 / FUNKDATION 賽事資料」
- 每次修改立即存檔，每 5 分鐘自動備份（保留 20 份）
- **設定**頁可匯出整個賽事（含素材）、還原備份、清除比賽結果
- OBS 可加入瀏覽器來源 `http://localhost:3010/output/`（OBS 在同網路另一台電腦時用 `http://<電腦的 IP>:3010/output/`），**寬度一定要設 1920、高度 1080**（OBS 預設 800×600，沒改畫面會糊；尺寸不對時 OBS 畫面左上角會出現黃色提醒）

## 開發

```
npm install
npm start            # 開啟桌面版
npm run server       # 只開伺服器，用瀏覽器操作
node test/e2e.js <素材資料夾> <截圖資料夾>   # 整場流程實測
```

推送到 main 或在 Actions 頁手動執行，GitHub 會自動打包 Windows 與 Mac 版，以 `v1.0.<次數>` 發布到 Releases。已安裝的程式啟動時會自動檢查並詢問是否更新。
